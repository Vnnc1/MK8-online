            Como testar em duas máquinas
            
      
              
    1. Cada PC instala o Launcher e prepara o jogo com os próprios arquivos (mesma versão 4.0.1).
      2. 
              
    2. Na mesma rede: libere UDP 47820 no firewall do anfitrião. Pela internet: use o código MK8-… do relay.
      3. 
              
    3. O anfitrião cria a sala e envia um convite individual a cada amigo (vale por quatro horas).
      4. 
              
    4. Depois de conectar, todos usam Jogar na sala. No menu do jogo, segure L + R e pressione o analógico esquerdo para LAN Play: o anfitrião escolhe Create Room e os convidados entram pelo Lobby.
      5. 
              
    5. Se falhar, cada pessoa gera um relatório em Suporte e envia o .zip.
      6.
